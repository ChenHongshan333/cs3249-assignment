- Section (paper) "流程的三个主要环节": 论文说 shape 生成模型由两部分组成：一是把 polygon mesh 压缩成潜空间连续 token 的自编码器，二是在该潜空间上训练、以用户图片为条件预测 token 序列的扩散模型；预测出的 token 再经 VAE 解码器还原为网格。论文同时指出，给定输入图片后，Hunyuan3D-DiT 先生成 bare mesh，之后才进入纹理生成阶段。  [cites: 2e0d0789-p004-c01, 2e0d0789-p003-c04]
